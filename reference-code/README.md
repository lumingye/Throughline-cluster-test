## 怎么跑

这些是**扁平模块**，不是安装包。在本目录下直接运行：

```bash
# 零成本、不联网、不调模型的四件
python length_census.py 快照.jsonl
python scan_explicit_refs.py 快照.jsonl --dump refs.tsv
python nesting_check.py
python audit_verify.py 审计报告.json 审计正文.md

# 会真的把原文发往你配置的对话服务
export MEMAGG_CHAT_API_BASE=...
export MEMAGG_CHAT_API_KEY=...
export MEMAGG_CHAT_MODEL=...
python min_run.py 快照.jsonl --sample 20
```

输入契约只需要两样：**记录标识 + 正文**。支持 JSON / JSONL / SQLite 快照，
列名可用 `--id-col` / `--text-col` 覆盖。

`normalization.py` / `micro_units.py` / `schema.py` / `a0_prompt.py` /
`b_judge.py` / `blocking.py` 是库，不是脚本；它们之间用**平级导入**
（`from normalization import ...`），因此要么在本目录下用，要么把本目录加进
`sys.path`。

## 读这些代码时要知道的五件事

### 1. `min_run.py` 是**故意笨**的

它的归组**只按「对象」的字面做精确匹配**——不算向量、不认别名、不做聚类。

笨是有目的的：它给出一条**下限**。

- 若笨办法排出来的东西已经接近人工样张 → 那些复杂召回通道现在**还没有理由**；
- 若笨办法明显更差 → **差在哪一眼就能看见**，那才是该修的地方。

**不要「顺手」把它改聪明，那会毁掉这次测量。**

### 2. 位置（span）永远不是裸的 `[start, end)`

一个位置只有相对于特定的 `source_hash + normalization_version + offset_unit`
才有意义。`normalization.py` 独占归一化与哈希，**保证每个调用点用的是同一条规则**。

这条是从一次真实缓存缺陷来的：旧代码写入缓存时用未 strip 的文本算键、读取时用
strip 后的算，于是**缓存永不命中**，静默全量重跑，只表现为「怎么这么慢」。
**所以键只在一个地方算。**

### 3. 微单元只是坐标，不是语义单元

`micro_units.py` 的输出完全确定性（同输入 → 同输出），但它**什么都不宣布**：

- 空行**不是**语义边界；
- 标点**只**用来推导确定性的句/小句坐标窗口；
- 长度**不**决定切分；
- 小节标题**不**自动成为父节点。

它保留了两层信息：叶子坐标类型（句 / 小句 / 编号条目 / 字段行 / 标题）与它所属的
行级结构类型，这样后续想换一种观察粒度时不必重新解析。

### 4. 证据契约：模型给位置，系统给文本

`b_judge.py` 里最值得看的是 `_validate_evidence()`。

模型只返回 `(side, start, end)`。导入器负责：校验侧别、校验位置在记录范围内、
校验位置落在该语义单元自己的来源片段内、**从真实记录确定性地切出规范摘录**、
绑定真实的来源标识与哈希。

旧响应里残留的 `excerpt` 字段被**有意忽略**——因为要求模型逐字复制原文，会让
引号规范化这种排版问题拥有否决语义判断的权力（实验记录 E12 有一次真实案例）。

> **模型永远不复制出处元数据或权威原文。**

另外注意 `typed_edge()` 与 `identity_mergeable()` 是**两个不同的方法**：四种关系
都是真实的边，但**只有「同一」可以并查集**。其余三种被压平成同一性，会把
**已经被正面判定为「不是同一件事」**的对合并掉。

### 5. `blocking.py` 不做统一总分

各通道的分数**只在自己的通道内有意义**，从不跨通道比较。并集的交付顺序是：
确定性通道优先（且不被软通道预算裁掉），其余按各自通道内的名次**轮转交错**，
避免某一路淹没其它路。每个候选保留**全部**通道的来源记录。

还有一条硬约束写在数据结构里：候选的写入序号必须早于查询的写入序号，
否则直接抛错——**候选池不得包含 query 之后才出现的记录**，这条不能只写在文档里。

## 安全提醒

- `min_run.py` **会把选中记录的原文发往你配置的对话服务**，也会在终端打印原文片段。
  只在本地看，不要把输出贴到公开的地方。
- API key 只从环境变量读，不落盘、不打印、不进缓存。
- `length_census.py` / `scan_explicit_refs.py` / `nesting_check.py` / `audit_verify.py`
  **不联网、不调模型、不写任何东西**；`--dump` 导出的也只有标识对，无正文。
- `audit_verify.py` 只读一份已经脱敏的审计报告，**它自己不接触任何私有产物**；
  它做的是相反的事——检查那份报告有没有把不该出现的东西带出来。
