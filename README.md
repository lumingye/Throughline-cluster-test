# 个人记忆聚合 · 实验记录

一个单人书写的中文个人记忆库（约 1,600 条）上，关于**切分与聚合**的一系列实验记录。

**这份东西的用途是给别人做参考。它记的主要是失败：每一项实验的产出都是删掉一个此前被默认为真的前提。**

---

## 三份材料

| 文件 | 内容 |
|---|---|
| [`EXPERIMENT_REPORT.md`](./EXPERIMENT_REPORT.md) | **正文。** 十三项实验，一项一节：要回答什么问题 / 怎么做的 / 结果是什么 / 否决了什么 / 结论有多弱。后面接三条横跨多项实验的切分结论、被否决做法的汇总表、以及通用方法学教训 |
| [`REFERENCES.md`](./REFERENCES.md) | 参考方案与文献。分「正文引用的」和「查阅过但正文未引用的」两部分，每条注明可靠度等级与该工作自身的适用边界 |
| [`reference-code/`](./reference-code/) | 脱敏后的统计脚本与参考实现，含各自对应哪一项实验、以及有没有真跑过 |

---

## 建议的读法

**只有十分钟**：正文 §0（这份文档是什么）+ §16（被否决的做法汇总）+ §17（通用方法学教训）。

**只关心切分**：正文 §15 是三条横跨多项实验的结论——**为什么不用脚本切**、**提示词才是切分行为的主开关**（同一套流程会因为提示词写法落到「过度切分」或「完全不切」两个极端）、**为什么要先切再合**（不切的话，「合」是在判一个混合物）。

**想复现某一项**：正文里找到对应的 `E#`，再到 `reference-code/` 找对应的脚本。

**想引用外部工作**：先看 `REFERENCES.md` 的可靠度等级——里面有相当一部分是
【二手未核】或【社区风向】，**不能直接当证据用**。

---

## 三条使用前的提醒

**① 这里没有可以照搬的方案。** 十三项实验没有一项证明某个聚合方案可用。价值在删除，不在建设。

**② 结论几乎全是「存在性」，没有比例含义。** 除两项全库统计外，最大的一项是 60 张卡 / 12 组，
人工标注部分是个位数。单一语料、单一作者、单一语言。

**③ 合成材料上的结果不能外推到真实材料。** 报告里有一项在刻意构造的合成卡组上测容器抵抗力，
而同类失败在真实材料上要难看得多。两者的差距从未被量过。
