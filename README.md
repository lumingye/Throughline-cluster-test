# 个人记忆聚合 · 实验记录

一个单人书写的中文个人记忆库（约 1,600 条）上，关于**切分与聚合**的一系列实验记录。

**这份东西的用途是给别人做参考。它记的主要是失败：每一项实验的产出都是删掉一个此前被默认为真的前提。**

---

## 在这个库上被否决的做法

先给结论。**范围是这一个库**，样本很小，细节与数字见正文 §19 与补遗 S10。

| # | 做法 | 为什么不行 |
|---|---|---|
| 1 | 靠向量把相似的自动聚成堆 | 这个库的向量里没有天然的堆，36 组扫参都是那样 |
| 2 | 让模型给聚出来的堆起个名当主题 | 碰巧凑一起的东西也能被起出一个听着像那么回事的名字，越小的堆越容易编 |
| 3 | 靠「有同一个人 / 同一段关系 / 同一个习惯 / 同一个大话题」分组 | 这些是**筐**，不是**核心**；而模型天生爱把筐当核心 |
| 4 | 靠标签分组 | 标签跟正文同一个人写的，没资格当裁判；记录切开后每段还会继承整条标签 |
| 5 | 按换行、空行、句号、字数切 | **该切的地方不动、不该切的地方乱切**，两头同时错，没有阈值可调；人根本不看空行 |
| 6 | 不切就直接聚合 | 一条记录装着三件事时，「跟另一条是不是同一件事」这个问题**本身没有定义** |
| 7 | 让模型逐字抄原文当证据 | 它会把直引号改成弯引号，于是判断完全正确的结果被判失败 |
| 8 | 指望模型自己说「我不确定」 | 专门做了 4 道模棱两可的题，一次都没说，全给了确定答案 |
| 9 | 靠改提示词去救上游的烂输入 | 改了九版，最后两版之间几乎没区别——东西本身是混的，怎么调都是在给混合物贴标签 |
| 10 | 用「跟人的一致率」验收切分 | 「从来不切」跟自己永远一致，任何一致率都打不倒它。唯一能问的是：**人明确说不该切的地方，它切了没有** |
| 11 | 让模型给每条抽个「话题」，再按话题分组 | 抽出来 **60 个话题，零重复**，一组都没凑上。同一件事换个说法就是另一个话题 |
| 12 | 拿标签或话题的**向量**当门槛 | 意思无关的两个算出来 **0.537**，同义的两个算出来 **0.522**——**反的**，找不出可用的阈值 |
| 13 | 挨个两两对比，把所有对都问一遍模型 | 材料翻倍、对数翻四倍；而且单次结果没分辨力，每个结论还得重复采样。真实规模上跑不动 |
| 14 | 同时要「弱联系也留着」和「不同的堆能分开」 | 堆之间还必须允许重叠，所以不能靠「一条只属于一个堆」断开传递。弱联系一留，任意两堆之间都有几条说得通的线——**切在哪都错** |

其中有四条**看起来跟语料没什么关系**，多半到哪都成立：**筐被当成核心**（#3）、**逐字抄原文当证据太脆**（#7）、**模型不肯说不确定**（#8）、以及 #10 背后那一整类陷阱——**分不出「做对了」和「它总是这么答」**（正文 §20.3）。

如果只带走一句，建议是最后那个。

**另外三条值得单独说**：#11 / #12 只判掉了「把话题当门槛」，**没有**判掉「把话题当参考材料之一」——这个区分是补遗 S10 里最重要的自我更正。#14 是这条路线实际停下来的地方，它不是某个指标不达标，是两个要求互相排斥。

## 建议的读法

**只有十分钟**：正文 §0.0（对上一版的四处更正）+ §19（被否决的做法汇总）+ §20（通用方法学教训）。

**只关心切分**：正文 §18 是三条横跨多项实验的结论——**为什么不用脚本切**、**提示词才是切分行为的主开关**（同一套流程会因为提示词写法落到「过度切分」或「完全不切」两个极端）、**为什么要先切再合**（不切的话，「合」是在判一个混合物）。

**只关心「合」**：先读正文 E2 / E3 / E11 / E12，**再读 E14–E16 与补遗 S9**——后两者会削弱 E11 / E12 的一部分旧归因，不能跳过。

**只关心「该拿什么当线索」**：补遗 **S10** 一次给出标签、词面 n-gram、标签向量、话题抽取、话题向量五种做法各自的失败方式，以及为什么它们**必须叠着用，不能串着用**；**S11** 补上「两两对比这条路本身撑不住」和「感想类文本上精确字段可能强过话题向量」。

**想知道这条路线最后停在哪**：正文 **E16** 末尾两节。

**想复现某一项**：正文里找到对应的 `E#`，再到 `reference-code/` 找对应的脚本。

**想引用外部工作**：先看 `REFERENCES.md` 的可靠度等级——里面有相当一部分是
【二手未核】或【社区风向】，**不能直接当证据用**。

## 四条使用前的提醒

**① 这里没有可以照搬的方案。** 十六项实验加十一项补遗，没有一项证明某个聚合方案可用。价值在删除，不在建设。

**② 结论几乎全是「存在性」，没有比例含义。** 除两项全库统计外，最大的一项是 60 张卡 / 12 组，
人工标注部分是个位数。单一语料、单一作者、单一语言。

**③ 合成材料上的结果不能外推到真实材料。** 报告里有一项在刻意构造的合成卡组上测容器抵抗力，
而同类失败在真实材料上要难看得多。两者的差距从未被量过。

**④ 单次运行的分数没有分辨力。** 同一合同下重复采样显示，联合判定完全稳定的案例是 **0/10**。
看到任何 ±1 的比较，**先问它有没有噪声底**。
